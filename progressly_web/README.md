# Progressly

A React + JavaScript student project for tracking learning progress, journal entries and skills.

## Run the project

```bash
npm install
npm run dev
```

## Main React topics used

- JSX and functional components
- Props
- State and useState
- useEffect
- Forms and event handling
- Arrays and objects
- map, filter and simple loops
- localStorage and JSON
- CSS Flexbox, Grid and responsive media queries
